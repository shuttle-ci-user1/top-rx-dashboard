# Top Rx Dashboard

Top Rx Health Checkup & Performance Dashboard — self-contained HTML.

## Live
Open `top_rx_dashboard.html` or visit the GitHub Pages link below.

## Tabs
- **Health Check** — cluster matrix with quality/price/depth distribution
- **Performance** — cluster performance with 9 working filters (Cluster, Region, Biz Class, Rest Quality, Item Quality, Price Bucket, Depth Bucket, Deal Duration, Is Image)
- **Fatigue** — deal duration fatigue analysis
- **Top/Bottom** — top/bottom 50 items & restaurants
- **Dish Family** — dish-level aggregation
